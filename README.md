Purpose of the Project

Build a simple Django REST API for a professional social platform to practically understand how Django, DRF, authentication, models, ORM, relationships, permissions, and CRUD operations work together.

Problem Statement

Users need a platform where they can:

Create and manage their accounts
Maintain their profiles
Create, view, update, and delete posts
Access only the resources they are authorized to modify

The project focuses on real backend development using Django ORM and REST APIs, without unnecessary advanced architecture.
